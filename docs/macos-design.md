# macOS 0.1.10 设计说明

## 目标

先回答三件事：蜂窝数据是否开启、套餐用到哪里、短信转发的开关与最近处理状态。联网开关不等于互联网连通，转发开关不等于消息送达；不使用绿色成功标记混淆这些事实。

## 结构与视觉

- 原生材质侧边栏承载八个目的地，保留既有控制器页面索引；表格选择与程序导航双向同步，支持键盘选择。
- 首屏连接与套餐并排，本机今日流量及上下行速率次之，接口信息和短信状态独立分组。
- 系统字体、等宽数字、语义文字与蓝色强调、12 pt 圆角与细分隔线；移除旧 under-page 深灰底。背景随系统外观适配，无 WebView 或外部设计依赖。
- 菜单面板 400×700 pt，重要信息先出现，异常长文案可滚动。主窗口默认 1040×760，最小 1000×700；内容区宽度跟随窗口，长页可滚动。
- 菜单栏维持固定点击宽度，左侧状态图形由 SF Symbols 提供，保留浅蓝待命、蓝色开启、琥珀警告及辅助功能标签。
- 百分比环只呈现已确认套餐数据；估算与来源时间显式标注，未知状态显示破折号。

## 套餐上限

Mac 启动时统一采用运营商比例保护，设置不再暴露旧 GB 额度。旧额度授权在迁移时撤销自动接管，避免扩大消费授权；现有套餐授权保持。旧字段仅用于兼容回滚，Windows 不受此 Mac 迁移函数影响。80% 本次确认、98% 锁定和 6 小时查询过期保护沿用原实现，不增加后台收费短信。

## 验证

构建入口 `script/build_and_run.sh --package` 执行测试、签名、打包 UI 与 DMG 校验。UI smoke 使用隔离委托，生成八页深浅色、菜单面板和状态图标快照；检查双向导航、两个窗口尺寸、长页滚动、输入保留和禁用状态。测试图标注模拟数据，不能用来证明真实联网或消息送达。
