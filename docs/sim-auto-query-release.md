# Mac 0.1.14：换卡后自动查询套餐

“运营商套餐”页新增原生开关，默认关闭。请先核实该 SIM 的短信服务号和查询指令，再开启并确认可能的短信费用。首次开启也会为当前卡尝试一次。

## 安全行为

- 当前版本仅保存一组明确授权的运营商、服务号及指令；不是跨运营商自动猜测指令。非漫游且运营商匹配才自动发送；其他运营商需手动查询或重新授权。
- 每张 SIM 每 24 小时最多自动尝试一次，全部 SIM 合计最多三次。记录存本机，仅含 HMAC 指纹和时间；手动查询仍独立确认。
- 先写入尝试记录再发送，即使崩溃、无回复、超时或发送失败，也不自动重试。重启、重插、等待限额到期本身不会触发重复发送；必要时手动查询。
- 发送前再次读取 SIM 和运营商；授权撤销／睡眠后排队请求作废。已经交给模块的短信不能撤回。
- 查询记录损坏、版本未知或不可用时自动查询暂停，不清空记录重发。确认设置保存失败时不授予新授权。
- 查询不主动开启 4G；新卡套餐未知前继续保护性暂停接管。既有 Wi-Fi 优先、80% 确认和 98% 停止规则不变，套餐估算仍不是实时账单。
- 同时修复 0.1.13 的 SIM READY 枚举比较错误，以及 NOT READY 的宽松字符串匹配，防止无法绑定套餐或误判。

## 交付范围

仅更新 Mac。Windows 仍为 0.2.0-preview.3，不含此开关。Mac 安装包仍是 ad-hoc 未公证版本。不替换正在运行的应用，不自动授权新功能，也不发送真实查询／iMessage，不删除模块短信。

自动化验证使用合成卡身份、伪造 AT 返回和隔离界面。实际换卡及运营商回复解析仍需要设备与人工授权验证，不把模拟结果称为实机通过。

## 验证结果（2026-09-27）

- 315 项自动化测试通过，1 项跳过（Mac Python 不含 Tk 的 Windows 界面测试）；Ruff、严格 mypy 均通过。
- 新增 35 项回归，覆盖授权／取消、配置保存失败、SIM 就绪绑定、跨卡过滤条件重置、发送前身份再次验证、并发占位、24 小时频控、时钟回拨、重启去重和损坏记录安全暂停。
- 配置范围整体覆盖率 92.83%，选定核心模块 95%；并非完整 AppKit 或硬件覆盖率。
- 实际打包 arm64 App 的隔离 UI smoke 通过，检查八页深浅色、窗口缩放及新开关开／关回调；无真实短信或联网变更。
- 嵌套 ad-hoc 签名完整性、Info.plist、DMG 只读挂载和 SHA-256 核对通过；安装包仍未公证。未替换当前安装。
