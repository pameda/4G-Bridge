# 4G Bridge Windows 0.2.0-preview.2

同步 macOS 新版的流量展示，不包含 iMessage 或短信转发。

## 本次更新

- 总览突出当前套餐估算已用百分比。
- 环形图和数字按用量变色：低于 60% 蓝色，60% 起橙色，75% 起红色提前预警。
- 三个保护区间明确标记“当前区间”，不用仅靠颜色辨认。
- 百分比不四舍五入跨越 80%／98% 边界；未知用量显示“—”。
- 保留 Wi-Fi 优先、80% 确认、98% 停用及原有隐私保护；显示变化不会解除锁定或自动授权。
- 新增浅深色、多阈值、六页布局及渲染无副作用验证。

## 安装

退出旧版后运行 `4G-Bridge-0.2.0-preview.2-windows-x64-setup.exe`。也提供完整便携 ZIP；请核对 `windows-SHA256SUMS.txt`。设置与流量保护记录保留。

安装包未签名，可能出现 SmartScreen 提示；不关闭系统安全保护、不安装额外驱动。
