# 安全与可靠性更新

Mac 0.1.13；Windows 0.2.0-preview.3。不新增权限或第三方依赖。

## Mac

- SIM HMAC 独立套餐与计量，换卡撤销本次授权；首次升级需重新查询套餐，旧数据保留并备份，不自动发送收费查询。
- Messages 接受后逐段核验设备／SIM 和 PDU 内容才清理；旧待清理记录安全暂停，不盲删或重发。
- iMessage 目标和正文改走标准输入，不出现在进程参数、环境变量或临时文件中。
- 数据库异常／版本过新暂停转发与清理，不重建空去重库；升级前备份，保留已有 hash／状态。
- 包含此前已完成的整行侧栏点击、突出百分比和分级预警界面改进。

## Windows

- 系统事件唤醒、250ms 合并通知、2秒轮询兜底；无额外定位权限。
- DNS/TLS/HTTP 独立进程，整轮6秒上限；关闭／睡眠／网络变化可取消，测试验证回收。
- 计量与长时间网卡切换分锁，开启提交前重新核验取消和额度；中文原因与建议操作。
- 保留 Wi-Fi 优先、80% 确认、98% 锁定；不含 iMessage 或短信转发。

## 安装与边界

退出旧版后安装，保留用户设置。Mac 首次升级需要重新查询套餐。不要直接降级打开新数据库；需使用配套备份并人工核对备份后可能丢失的去重记录。

Mac 仍是 ad-hoc 未公证包，Windows 仍是未签名预览版；不绕过 Gatekeeper／SmartScreen。Windows 无真实 QDC507，模拟／云端通过不等于实际联网已验收。未执行真实发信、删除短信、收费联网或主动断网。

既有构建依赖审查项、正式签名及更广泛安全审计不在本轮关闭范围；不能将本更新称为无漏洞认证。
