# 网络测速与月度统计

## 使用

侧栏选择“网络测速”。默认轻量 Wi-Fi：下载 8 MiB、上传 2 MiB；标准 32 MiB＋8 MiB。每次开始前确认，支持取消，没有后台测速。4G 专项要求按现有套餐规则先开启数据，测速不会开启它；保留 80% 确认、98% 停止和保守余量检查。当前网络模式可能经过 VPN 或消耗 SIM 流量。

使用系统 curl 访问固定 `https://speed.cloudflare.com/__down` 和 `__up`，只上传内存随机数据，不读用户文件，不发送业务内容。禁用 curlrc、环境代理和重定向，不关闭 TLS 校验。Wi-Fi／4G 专项的下载、上传及 HTTPS 延迟测量绑定对应网卡，不切换网卡重试。为避免 VPN 虚拟 DNS 地址阻止专项连接，测速前经当前系统网络访问 Cloudflare DoH，仅解析唯一测速域名；响应限 4 KiB、仅接受公网 IPv4，并保留测速主机 TLS 校验。这一步可能经过现有 VPN 或其他默认网络，不计入带宽结果，不改系统 DNS。当前网络模式的全部请求保留系统 DNS／VPN。服务方可见公网 IP。没有额外上报，也不持久化测速结果。

解析协议参考 [Cloudflare 官方 JSON API](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/) 和 [官方地址说明](https://developers.cloudflare.com/1.1.1.1/ip-addresses/)。解析服务或测速服务不可达时停止，不静默改用其他线路、服务商或关闭 VPN。

显示的是单连接有效载荷除以包括连接建立的耗时，单位 Mbps，轻量测试不代表峰值带宽。延迟是三次 HTTPS 首字节时间的中位数；抖动是相邻样本差的平均值，不是 ICMP ping 或完整线路质量评分。取消／超时可能已经传输部分载荷；界面的已完成载荷不包括未完成部分、协议开销和其他应用用量。实际收费以运营商为准。

## 每月更新

使用 Mac 本地自然月。打开已授权的“三网智能查询”后，在月初应用首次运行／唤醒并识别非漫游 SIM 时尝试查询，仍遵守同卡至少 5 小时间隔和所有卡 24 小时最多 8 次。应用退出、Mac 关机或模块未就绪时不会准点发送；恢复后补做检查。

本月手动套餐保持到月末；新月尝试查询，失败需手动填写。上月未解析查询允许新月一次新查询，当月失败不反复发短信。未知余额、过期套餐、换卡或运营商回复只有网页入口时，都不会自动推断为满额。解析出有效新月套餐后按原有 Wi-Fi 优先和套餐保护重新判断，不强制覆盖用户手动关闭的数据或接管开关。

“本机流量”按月展示下载、上传和合计，历史保存于本机 SQLite，界面显示最近 12 个月。只统计应用运行期间观察到的 QDC507 网卡计数，所有 SIM 合计；不包含 Wi-Fi 或软件关闭期间的完整用量，不等同运营商账单。计数差额归入采样时间所在月份，跨月边界存在一个采样间隔的归属误差。月初统计从零开始，但不清空旧月记录，也不代表套餐自动恢复满额。

## 验证边界

自动化测试使用合成时间、流量和网络响应，不更改系统时间、真实套餐或短信。实际跨月长期运行及三家 SIM 的全部账单模板尚未验收。Windows 测速界面未包含在本次 Mac 更新内。
