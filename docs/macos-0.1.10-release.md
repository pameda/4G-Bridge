# 4G Bridge Mac 0.1.10

这次更新重做了 Mac 版界面，并将 4G 上限统一为运营商套餐总量。Windows 版不受影响。

- 原生侧边栏替代顶部八个按钮；连接总览并排展示蜂窝状态与套餐环形图。
- 统一系统配色、字体、间距和轻量分组；支持浅色、深色、窗口缩放与长页面滚动。
- 菜单栏使用系统状态符号，快速面板重新排布；本机流量与运营商套餐分开显示。
- 设置不再要求手填 GB 或追加额度。低于 80% 正常使用，达到 80% 提醒并确认，达到 98% 自动关闭。套餐未知或查询超过 6 小时时暂停开启。
- 旧手动额度的授权不会自动升级为套餐授权，需要重新确认自动接管；已授权套餐模式保持。短信与钥匙串实现不变，不增加后台收费短信。

## 安装与验证

下载 DMG，将应用拖入“应用程序”；附 SHA-256。Apple Silicon，macOS 15 及以上。ad-hoc 签名，未公证，可能需要正常的首次打开确认；请勿关闭系统安全保护。

238 项自动化测试、Ruff、mypy、敏感信息扫描通过；真实打包应用的八页深浅色、菜单面板、导航、缩放与状态检查通过；DMG 已只读挂载验证。

已在本机普通启动后检查实际窗口、模块识别和套餐上限显示；检查时数据关闭。此轮未主动开启 4G、发送运营商查询或发送测试 iMessage，不能把界面验证当作真实断网接管／消息送达验收。套餐是运营商快照加本机新增流量的估算，不是实时账单，不能保证绝不超额。
