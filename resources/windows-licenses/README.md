# Runtime license provenance

Official CPython 3.14.7 Windows builds use Tcl/Tk 9.0.4; see
https://github.com/python/cpython/blob/v3.14.7/PCbuild/tcltk.props .
The installed runtime omits the standalone upstream `license.terms` files,
so we redistribute their notices with our bundle. No third-party source code
or executable is vendored here. Trailing whitespace is normalized.
