# 4G Bridge

联通 10010 的当月国内通用“流量提醒”现在可直接更新套餐：从明确的已用＋剩余计算总量，不需要额外发送查询。只接受核验到当前联通 SIM 的近期通知，保留运营商计费截止时间；共享套餐及延迟通知均标为估算，不代表实时账单。混合／定向套餐不猜测，旧报告不覆盖新数据。通知正文不落盘。

查询短信未返回完整数值时，可在“运营商套餐 → 查询不到？手动设置套餐”填写总量与剩余量，确认后启用 Wi-Fi 优先的自动接管。手动额度绑定当前 SIM，本自然月有效，并继续执行 80% 确认／98% 停止；不自动清零或虚构套餐余额。详见 [套餐查询与手动设置](docs/smart-carrier-query.md)。

4G Bridge 是面向 Apple Silicon Mac 与 DJI / Baiwang QDC507 的原生菜单栏工具。它读取模块中的 SMS，在成功组装与去重后，通过 macOS Messages AppleScript 接口将内容发送给用户指定的 iMessage 目标。

## 当前能力

短信转发格式（0.1.23 起）：直接显示完整短信正文，空一行后在末尾显示“来自：发件人”和“时间：本地时间”。已发送的历史消息不改写、不重发。

稳定使用目标仍为 macOS。另提供独立的 [Windows 预览版](WINDOWS.md)（[安装包下载](https://github.com/pameda/4G-Bridge/releases/tag/windows-v0.2.0-preview.3)），不包含 iMessage；已通过 Windows 云端构建、启动及安装／卸载验证，QDC507 实机验收尚未完成。下列功能说明针对 macOS，Windows 范围与限制见其独立文档。

- 识别 `2CA3:4006` 与 `2C7C:0125`，每次连接重新扫描 USB bulk endpoint。
- 单一 AT 工作线程，串行 transaction，并将 `+CMTI` 等 URC 与普通响应分流。
- 读取 SIM、运营商、LTE 注册、RAT、CSQ/RSSI 与 ECM 网络信息。
- 支持 GSM 7-bit、扩展字符、UCS-2/UTF-16BE、Emoji 与 8/16-bit multipart UDH。
- Messages 正文和目标通过匿名标准输入管道传递，不进入进程参数、环境变量或临时文件，也不读写 `chat.db`。
- SQLite 只保存 hash、脱敏所需元数据、状态、重试次数和模块位置，不保存正文。
- “短信转发”页面增加收到的短信列表、搜索与完整正文查看／选择复制。仅在内存保留最近 200 条，本次退出或更换 SIM／设备清空；同卡重连保留。转发关闭或目标未授权时仍能接收查看，不因此发送或删除短信。已从模块删除的历史内容无法恢复。
- 正文随窗口宽度自动换行并可上下滚动。“补转发未发送…”仅处理当前列表中仍可从同一 SIM 读取的明确未发送／失败项；正在发送、已接受和结果不确定项不重发。补发需要原有转发开关和目标授权有效。
- 失败按 1、5、15 分钟重试；Messages 接受后，逐段核验设备／SIM 指纹和 PDU 哈希才删除模块短信。内容不一致或旧记录缺少核验信息时暂停清理，不重发。
- 数据默认 OFF；启动、USB 重连、睡眠、唤醒与正常退出均先执行安全关闭。已授权自动接管时，重新检测 Wi-Fi 后才可开启。
- 动态发现 ECM `enX` 与网络服务；从接口 counters 统计速度、本次、今日和本月流量。
- Wi‑Fi 可上网时优先；4G 上限取运营商套餐总量，80% 需确认、98% 关闭，可选故障自动接管，保留现有 VPN 配置。
- 菜单栏左键打开紧凑快速面板，右键显示完整菜单；原生侧边栏提供总览、本机流量、运营商套餐、短信转发、应用网络、设备、日志与设置。
- 总览显示连接、速度、今日流量和转发状态；流量页显示本次／今日／本月统计及内存中的真实速度趋势。
- 原生 AppKit 侧边栏、系统材质、轻量分组、SF Symbols 和等宽数字；支持可缩放窗口、页面滚动与跟随系统／浅色／深色。
- 短信测试、投递不确定项重发和确认清理均需再次确认；未保存的目标编辑不被后台刷新覆盖。
- 正确解析禁用网络服务，只控制明确识别的 QDC507；通用 USB 网卡不会被当成模块。
- 取得有效 IP 和网关后才显示数据开启；ECM 链路不能恢复时，仅在用户确认开启后重启模块一次。

## 安装

1. 打开 `artifacts/4G-Bridge-0.1.22-arm64.dmg`。
2. 将 4G Bridge 拖到“应用程序”。
3. 首次启动若 Gatekeeper 提示，在“系统设置 → 隐私与安全性”中确认打开。
4. 在设置中填写含国家区号的手机号（中国大陆为 `+86`）或 iMessage 邮箱，保存到 macOS 钥匙串；不会自动猜测国家区号。
5. 先点击“检查连接”（不发送），再自行确认“发送测试消息”。第一次检查或发送时，macOS 可能请求控制“信息”的 Automation 权限。
6. 使用本软件前退出其他 QDC507 控制器，避免争用 AT 通道和网络开关。

### 0.1.13 安全升级注意

- 套餐改为当前 SIM 的本机 HMAC 指纹独立账本，不保存 ICCID 原文。旧无归属套餐留存并备份，不能直接用于开启数据；首次升级需重新确认并查询套餐，不会自动发送查询短信。
- 转发库升级前保存一致性备份，旧 hash／状态保留；旧待清理记录进入“安全暂停”。不要人工改库强行清理。
- 数据库版本过新或损坏时，暂停转发和删除，不自动重建空去重库。异常文件保留，备份位于应用支持目录 `backups`。请退出所有版本后进行恢复；不要把新版库直接交给旧版应用，旧版可能重建去重库。
- 回滚必须使用配套备份，且会失去备份后产生的记录，存在重复转发风险；恢复后应先关闭自动转发并人工核对模块消息。安装更新不代表已完成真实短信或联网验收。

流量显示仅统计应用运行期间观测到的 QDC507 网卡 counters，不是运营商账单、套餐余额或应用级用量；未取得采样时显示“—”，不会填入演示数字。速度趋势只保存在内存，采样中断／网卡变化后清空。

**4G 上限就是套餐上限**：设置页不再要求另填 GB，也不提供“追加额度”绕过套餐保护。使用运营商快照与本机新增流量估算已用比例：80% 前正常使用，80% 起需要确认本次连接，98% 自动关闭并锁定。套餐未知或查询超过 6 小时时禁止开启，需手动查询。旧手动额度的授权不会自动升级成套餐级授权，需重新确认自动接管；已授权的套餐模式保持。查询短信仍需单次确认，估算不是实时账单，不能保证绝不超额。

这是 ad-hoc 签名、未公证的 V1 构建；它不申请 Accessibility、Full Disk Access，不要求关闭 SIP，也不安装内核驱动。

连接检查只验证脚本服务与目标对象可解析，不验证收件人开通状态。Messages 返回成功也不是送达回执，请在“信息”里确认有无红色发送失败标记。超时或发送结果不确定时，自动转发保留模块短信并停止自动重发，交由人工核对。`--bridge-check` 可只输出本机检查错误码，不接触 USB、短信或清理队列。

ad-hoc 应用更新后可能需要重新授权钥匙串访问。后台读取不会弹窗或一直等待，未授权会明确显示错误；请点击“授权读取目标”，自行处理 macOS 的钥匙串授权，然后检查连接。不会索取 Apple ID 密码或 Token。

**Wi-Fi 下也支持转发**：QDC507 通过 AT 接收 SMS，Messages 通过 Mac 当前可用网络发送 iMessage；无需打开 QDC507 的 4G 数据。流量上限、自动接管是否开启与短信转发开关相互独立。模块仍需连接且 SIM 已注册；没有任何可用互联网时，转发可能失败。ECM 状态查询失败不再中断短信通道。

菜单栏使用固定 50 pt 点击区域和一体式蓝色矢量徽标；按实际 RSSI 显示档位，关闭时使用浅蓝暂停图形。模块缺失、切换中与保护失败各有独立图形和辅助功能说明，支持深浅色菜单栏和 Retina。

诊断可用 `open -n "dist/4G Bridge.app" --args --relay-diagnostics`：打开真实转发设置，但不启动 USB、自动转发、删除或 4G 自动接管。只有主动确认“发送测试消息”才会发送固定文本。窗口会明确显示“短信测试模式”，设备信息为“测试模式未检测”，不代表模块断开，无需反复拔插。

短信自动转发默认开启，目标保存在钥匙串；目标未配置、无效或未授权时等待配置，不读取模块短信、不消耗重试次数。手动关闭后会保存选择，后续启动不会强行重新开启；配置损坏时安全关闭。启用后可能处理尚未转发的积存短信，仍严格遵守去重、投递不确定不重发、Messages 接受后才清理的规则。

诊断结束后，点击总览的“恢复模块控制…”（或设备页“重新检测模块”）并确认，恢复 USB 检测、数据开关及流量保护；会先关闭数据，再按已授权的自动接管设置运行。短信转发恢复此前保存的开关，不再强制关闭。普通启动不会进入诊断模式。

## 开发

### 网络测速与月度统计（Mac 0.1.20）

- 侧栏“网络测速”或菜单栏右键菜单进入。默认 Wi-Fi 轻量模式：下载 8 MiB、上传 2 MiB 随机数据，另有协议开销；标准模式为 32＋8 MiB。每次确认后才开始，支持停止，不自动重试、不自动开启 4G。
- 可选 Wi-Fi、当前系统路由（包含 VPN）、已开启的 4G 专项。专项先经当前系统网络向 Cloudflare 解析唯一测速域名，下载／上传绑定所选网卡；不改系统 DNS／VPN，解析不可达则停止。显示单连接 Mbps、HTTPS 首字节延迟和三次采样抖动，不把轻量结果当成线路峰值或 ICMP ping。
- 测速使用 Cloudflare；服务方可见公网 IP，不上传短信、文件或 Apple ID，结果只在本次运行中保留。详情与边界见 [测速和月度统计](docs/speed-and-monthly.md)。
- “本机流量”增加最近 12 个月的下载、上传、合计。自然月自动分账并保留历史，只统计软件运行期间观测到的 QDC507 流量（所有 SIM 合计），不是运营商账单。
- 已授权三网智能查询时，月初首次运行／唤醒并确认 SIM 后尝试刷新套餐，仍遵守 5 小时间隔和 24 小时 8 次限额。本月手动套餐不重复查询；上月未知回复允许新月份一次查询，失败后等待手动处理，不假设恢复满额。未授权时不会自行发送短信。

### 应用网络、运营商套餐与运行日志

- “应用网络”及菜单面板显示系统进程实时上下行、本次观测累计。仅在界面可见时读取 `nettop` 的进程字节汇总，不抓包、不读取连接地址、不存储历史；VPN／代理／本地回环可能重复计数，不将进程用量误认为 SIM 账单，也不猜测物理出口。
- “设置 → 登录时启动”使用 Apple SMAppService；显示真实系统状态，不默认注册。建议先将应用移到“应用程序”。系统可能要求在“登录项”批准；仍沿用启动时的数据保护。
- “运营商 → 查询一次”在确认后只发送一条查询 SMS，不主动开启数据、不自动重试或定时查询。预填中国电信 10001 / 108，参考[电信官方短信服务表](https://m.gd.189.cn/gd/sms/)；地区、套餐和费用以运营商为准。其他服务号需自行核实指令。
- Mac 0.1.19 提供“自动识别运营商并刷新套餐”，需单独授权。开启后自动选择三网查询方式，同时授权 Wi-Fi 故障自动接管；新卡或无套餐时查询，完整回复成功约 5 小时后刷新。每张卡至少间隔 5 小时、所有卡 24 小时最多 8 次；先落盘再发送，无回复／结果不确定不自动重试。关闭自动接管不会被后续套餐回复重新开启。旧版单运营商授权保留原范围，需重新开启此开关才能扩大为三网与定时刷新。详见 [智能查询说明](docs/smart-carrier-query.md)。
- 回复原文遵循现有 iMessage 转发开关；转发失败不删除。套餐解析支持明确总量＋已用量或剩余量，以及电信逐项“手机上网国内流量”的总量／剩余量（含结转）；不合并无法确认的重叠套餐。只接受当前 SIM、当前查询、正确服务号和时间的回复；重启恢复 SIM 独立账本，不把模块中其他卡的历史短信当成当前额度。
- 菜单中环形图显示已使用百分比及短信更新时间；保护模式下明确标记“套餐＋本机新增 · 估算”。无完整数据为“—”。用于保护的必要数值、时间及计数保存在权限受限的本机 SQLite，不存短信正文。
- “运行日志”为中文安全事件列表，可筛选警告、复制、清空；只保留内存中最近 500 条，不记录正文、号码、Apple ID、地址或原始异常。


### 自动接管与流量上限

优先方案：“运营商”页启用 **80% / 98% 套餐保护**。低于 80% 可自动接管、不限速；估算达到 80% 先关闭并弹窗，确认只对本次连接有效；达到 98% 持久化锁定，不能用追加固定额度绕过。同月新查询不降低已经观察到的用量或清除锁定；下月收到完整的新套餐回复后才重新判定。

快照超过 6 小时、跨月未查询或计量异常时，停止自动接管并保护性关闭。三网智能查询经单独授权后会提前刷新；未授权时仍需手动查询。估算不是实时账单：运营商延迟、共享 SIM、应用未运行期间和断开延迟可能产生差异，无法保证运营商精确计费比例绝不越线。

旧的固定 GB 方案保留供未启用套餐保护时使用：

在“设置”填写上限（十进制 GB），选择“每份额度”或“每自然月”，开启自动接管并确认保存。初始没有额度，不会自行开启。额度内不限制上网内容或应用，不抓包、不按应用分流。

- 每轮检测后间隔约 2 秒；Wi-Fi 链路明确 inactive／接口不存在时直接请求接管，不等待三轮。Wi-Fi 仍连接但 HTTPS 失败时连续确认 3 次；Wi-Fi 连续 2 次恢复后关闭自动接管的 4G。模块 DHCP 或一次有界重启仍可能需要数十秒，不保证无缝连接。
- 测试仅在自动接管已授权且额度可用时运行，HTTP 连接绑定动态发现的 Wi-Fi 网卡、绕过代理，使用 Apple/Microsoft 的公开连接测试地址；不携带短信、目标号码或 Apple ID，DNS 由系统解析。
- 仅移动 QDC507 服务：故障时置于 Wi-Fi 前，关闭后恢复 Wi-Fi 优先。不修改 DNS、VPN 或静态路由。VPN 的 utun 默认路由保持；验证模块的 scoped 路由，不要求移除隧道。VPN 提供方仍负责自身迁移，接口就绪不代表 VPN 端到端成功；其他实体默认网络存在时仍暂缓。参见 [Apple 网络服务优先级说明](https://support.apple.com/en-mt/guide/mac-help/mchlp2711/mac)。
- 虚拟 DNS 导致固定探测失败时，仅对 Apple／Microsoft 测试域名使用绑定 Wi-Fi 的 AliDNS HTTPS JSON 查询及请求级 `--resolve`，短期缓存不超过 60 秒，不修改系统 DNS、不传任何用户访问域名。参考 [AliDNS 官方 API](https://static-aliyun-doc.oss-cn-hangzhou.aliyuncs.com/download%2Fpdf%2F171662%2FAPI_Reference_intl_en-US.pdf) 和 [curl 官方参数](https://curl.se/docs/manpage.html)。
- 自动接管授权包含必要时最多一次模块重启恢复，可能短暂中断短信接收；恢复失败即暂停，不循环重启，需要重新启用策略或手动检查。
- 配置额度后，手动连接的 4G 流量也受保护。独立线程以约 1 秒间隔采样上传＋下载；达到上限先持久化锁定，再关闭 QDC507 服务，失败使用模块安全关闭回退。
- 到顶后，重启／重插／跨月／提高上限不会清除锁定。点击“手动追加一份额度”并确认，获得与保存上限相同的新额度；日／月统计不清零。不存在无限忽略上限的开关。
- “每份额度”持续累计直到手动追加；“每自然月”仅在**未到顶锁定**时自然月切换清零。手动追加后的“额度已用”不等于整月总用量。
- 手动关闭数据同时关闭自动接管，避免立即重新开启。退出／睡眠先关闭；已授权策略可在重新启动／唤醒后重新检测。

这是应用运行期间的本机计量保护，不是运营商计费硬限额。采样、系统命令和网络切换存在延迟，可能超额；退出、崩溃、休眠期间无法持续保护。请预留余量并结合运营商限额服务。计量异常会关闭数据，不静默重置损坏的额度数据库。

## 安全边界

- 不修改 Messages 数据库，不伪造入站消息。
- 不存储短信正文，不在日志中记录完整手机号、ICCID 或 Apple ID。
